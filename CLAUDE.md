## Agent skills

### Issue tracker

Issues and PRDs live as GitHub issues, managed via the `gh` CLI (a GitHub remote must be connected first). See `docs/agents/issue-tracker.md`.

### Triage labels

Five canonical triage roles mapped to their default GitHub label strings. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `CONTEXT.md` + `docs/adr/` at the repo root. See `docs/agents/domain.md`.
